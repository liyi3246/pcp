# fetch.c 和 derive_fetch.c 说明文档

## fetch.c - 性能指标获取实现

### 文件作用

`fetch.c` 实现了 PCP 中获取性能指标值的核心功能。这是 PMAPI 中最重要的操作之一 - 从 PMCD 或归档文件中检索指标数据。

### 主要函数

1. **pmFetch()** - 公共 API 函数
   - 从指定的 PMID 列表获取当前性能指标值
   - 这是应用程序最常用的 PMAPI 函数之一
   - 返回包含所有请求指标值的 `pmResult` 结构

2. **pmFetch_ctx()** - 内部上下文感知版本
   - 支持指定上下文的获取操作
   - 被 `pmFetch()` 和 `pmFetch_v2()` 调用

3. **__pmFetch()** - 内部实现函数
   - 处理实际的获取逻辑
   - 支持实时连接（PMCD）和归档上下文
   - 处理派生指标的预处理和后处理
   - 管理 IPC 通信和 PDU（协议数据单元）处理

4. **pmFetchArchive()** - 从归档获取指标
   - 从 PCP 归档文件按时间顺序获取下一组指标值
   - 用于历史数据分析

5. **pmSetMode()** - 设置归档处理模式
   - 控制如何遍历归档文件
   - 设置时间窗口和方向（向前/向后）

6. **__pmUpdateProfile()** - 更新实例配置文件
   - 将当前的实例过滤配置发送到 PMCD
   - 优化数据传输，只获取需要的实例

7. **__pmRecvFetchPDU()** - 接收获取响应
   - 从 PMCD 接收并解码 PDU 响应
   - 处理高分辨率和标准结果格式
   - 处理错误和状态变化

### 工作流程

1. 应用程序调用 `pmFetch(numpmid, pmidlist, &result)`
2. 检查并处理派生指标（调用 `__pmPrepareFetch()`）
3. 如果需要，发送实例配置文件到 PMCD
4. 发送 FETCH 请求 PDU 到 PMCD
5. 接收并解码响应 PDU
6. 处理派生指标的计算（调用 `__pmFinishResult()`）
7. 返回包含所有指标值的结果

## derive_fetch.c - 派生指标获取处理

### 文件作用

`derive_fetch.c` 实现了 PCP 派生指标的获取和计算功能。派生指标是通过表达式从其他指标计算而来的虚拟指标。例如，可以定义一个派生指标来计算 CPU 利用率百分比或磁盘 I/O 速率。

### 主要函数

1. **__dmprefetch()** - 派生指标预获取处理
   - 在主获取之前调用
   - 扫描请求的 PMID 列表，查找派生指标
   - 为每个派生指标，提取表达式中使用的所有操作数指标
   - 构建扩展的 PMID 列表，包含原始指标和所有操作数指标
   - 返回扩展列表的大小（如果没有派生指标则返回 0）

2. **__dmpostfetch()** - 派生指标后获取处理
   - 在主获取之后调用
   - 接收包含所有原始和操作数指标值的 `pmResult`
   - 评估每个派生指标的表达式树
   - 计算派生指标值
   - 重写 `pmResult`，将计算出的派生指标值包含在内
   - 移除仅用于计算的临时操作数指标

3. **eval_expr()** - 表达式求值
   - 递归遍历表达式树
   - 从 `pmResult` 中填充叶节点（操作数）的值
   - 执行算术运算（+、-、*、/、等）
   - 处理类型转换和提升
   - 处理实例域匹配
   - 向根节点传播计算值

4. **get_pmids()** - 提取指标标识符
   - 递归遍历表达式树
   - 收集表达式中使用的所有有效指标的 PMID
   - 用于构建 `__dmprefetch()` 中的扩展 PMID 列表

5. **bin_op()** - 二元运算
   - 执行两个操作数之间的二元运算
   - 处理不同数据类型（整数、浮点数、字符串）
   - 执行类型转换和缩放
   - 支持算术、比较和逻辑运算符

6. **__dmpostvalueset()** - 值集后处理
   - 为每个派生指标创建新的值集
   - 从表达式树复制计算值
   - 处理不同的值类型（32/64 位整数、浮点数、字符串等）
   - 正确分配和复制内存

7. **adjust_constant()** - 调整常量
   - 处理表达式中的常量值
   - 确保常量具有正确的实例域
   - 为单例或多实例上下文调整常量

### 派生指标工作流程

1. 用户定义派生指标，例如：
   ```
   disk.dev.util = 100 * delta(disk.dev.total) / delta(hinv.map.percpu)
   ```

2. 应用程序调用 `pmFetch()` 请求 `disk.dev.util`

3. `__dmprefetch()` 检测到这是派生指标：
   - 提取操作数：`disk.dev.total` 和 `hinv.map.percpu`
   - 将它们添加到获取列表

4. 执行主获取以获取操作数值

5. `__dmpostfetch()` 处理结果：
   - 调用 `eval_expr()` 计算表达式
   - 对每个磁盘实例执行计算
   - 创建包含计算值的新 `pmResult`

6. 返回给应用程序的结果包含派生指标的计算值

### 支持的表达式功能

- **算术运算**：+、-、*、/、%
- **比较运算**：<、<=、>、>=、==、!=
- **逻辑运算**：&&、||、!
- **函数**：delta()、rate()、instant()、sum()、avg()、min()、max()、count()
- **条件**：? : （三元运算符）
- **常量**：数值和字符串字面量
- **类型转换**：自动类型提升和转换

## 两个文件的关系

这两个文件协同工作以支持派生指标：

1. **fetch.c** 提供核心获取机制
   - 处理与 PMCD/归档的通信
   - 管理上下文和连接
   - 在适当的时候调用派生指标处理器

2. **derive_fetch.c** 扩展获取功能
   - 在获取前拦截并扩展 PMID 列表
   - 在获取后计算派生指标值
   - 对应用程序透明 - 它们看到的派生指标就像真实指标一样

这种设计允许 PCP 支持强大的派生指标功能，同时保持 PMAPI 的简单性。应用程序不需要知道指标是真实的还是派生的 - 它们的使用方式完全相同。
